# 串口下载

# 关于启动方式（BOOT）

从系统存储器启动，即运行 Bootloader

# 一般情况

第一步：

B0 3.3V B1 GND -> 复位 -> 上位机下载

第二步：

B0 GND -> 复位

# 一键下载

CH340 有 DTR 和 RTS 两个输出，通过一键下载电路和 B0，NRST 相连，软件自动控制这两个信号，实现一键下载

B0 和 B1 始终接 GND

选择 DTR 低电平复位，RTS 高电平进入 Bootloader
